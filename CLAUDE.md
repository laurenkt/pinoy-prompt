# Pinoy Prompt

Vite + TypeScript PWA, no framework. See README.md for how the app works.

- Before opening a PR: `npm test` and `npm run build`. For UI changes, screenshot Home and the changed screens at 360px and 390px wide.
- Code review (including `/code-review`) checks the change against REVIEW.md as well as for bugs. Anything that breaks a point there is a finding.
